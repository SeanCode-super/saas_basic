## 采用的权威规范

| 问题 | 采用的依据 | 在天枢如何检查 |

| 怎样写安全的 Java 和验证应用控制 | CERT Java 提供 Java 编码规则，OWASP ASVS 提供应用安全验证要求。[SEI CERT Java](https://www.sei.cmu.edu/library/the-cert-oracle-secure-coding-standard-for-java/) · [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/) | 检查身份来源、租户归属、凭证交付、授权撤销和错误传播。 |

详细规则、语言参考、团队排版和合并检查见[工程规范](../STANDARDIZATION_POLICY.md)。这里使用 ISO 的公开标准说明确定审查范围，未开展第三方认证或完整 ASVS 等级评定。

## 关联回归

- **新租户交付**　每次开通签发独立的随机初始密码，数据库保存带盐哈希。创建响应禁止缓存，详情和列表不含口令。无痕 Chrome 从平台新建租户并读取回执，关闭、刷新及检查浏览器两种本地存储均未发现明文。随后从独立浏览器会话使用该口令登录新租户并进入工作台。固定 12 位和 32 位且要求四类字符的模板各自通过开通与登录。将模板设为 3 位却要求四类字符时，整笔创建失败，租户与配额均无残留。一次展示指回执交付方式。现有首次改密标记仍沿用原认证流程。
- **扩展应用与 AI**　通过真实 MySQL 验证发布模型、菜单授权、动态增查改删、字段归属及报表读取。归档后模型退出 AI 可查询目录。租户安装与升级测试覆盖重复执行、升级失败回滚和跨租户拒绝。
- **回收站与导出**　回收站仅接受支持的资源和当前租户登记的业务表，恢复用户、部门、文件时检查配额。按删除批次恢复关联行，先前单独删除的子行维持原状态。导出按登记的字段和当前用户的数据权限读取。
- **工作流**　通过生产 Mapper 查询有效办理人，禁用账号、已撤销角色绑定和其他租户用户均被排除。指定办理人不可用或 JSON 解析失败时，操作返回错误。两个后端接入点读取同一会话的工作流待办。
- **监控**　流程计数从数据库取数，页面将模块清单中未单独检测的项目标为“未单独检测”。流程数据库可查询和各模块业务健康分别呈现。
