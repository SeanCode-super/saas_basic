## 1. 工业级流程引擎架构

天枢云基深度内嵌 **Flowable 7.x 工业级流程引擎**，提供符合国际标准 BPMN 2.0 规范的企业级审批能力。

### 核心特性矩阵：
* **多租户流程原生隔离**：在流程部署、实例启动与任务查询全链路传递 `TenantContextHolder`；
* **复杂审批流转控制**：支持串行审批、多实例并行会签（满足一定比例通过或一票否决）、委派与动态加签；
* **多级灵活驳回**：支持驳回至上一审批节点、指定历史节点或直接驳回至流程发起人重新修改单据。

## 2. 审批流生命周期全景

```
[员工发起审批单]
       │
       ▼
[部门主管初审] ─── (驳回) ───► [退回发起人修改]
       │ (同意)
       ▼
[多部门并行会签 (财务 + 法务)] ─── (加签) ───► [特邀专家先审]
       │ (全部通过)
       ▼
[集团总经理终审]
       │ (同意)
       ▼
[流程归档 & 触发业务状态回调 (如 ERP 自动核销库存/CRM 生成正式合同)]
```

## 3. PC 与跨端移动审批协同

### 3.1 PC 审批大厅
* **可视化流程图渲染**：已走完节点标绿、当前处理节点高亮脉冲动画、未走节点灰色展示；
* **审批历史全迹留存**：每一步审批人的操作时间、意见备注、上传的凭证附件一屏纵览。

### 3.2 移动端灵动岛审批待办
* 销售与高管出差途中，移动端悬浮灵动岛实时弹出待办审批推送；
* 支持在手机屏幕上手写数字签名并自动嵌入审批记录，实现 10 秒无纸化快捷签批。
