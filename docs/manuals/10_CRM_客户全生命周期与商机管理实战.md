## 1. 客户全生命周期流转矩阵

天枢云基 CRM 覆盖从公域线索获取、公海池认领、商机挖掘、商务谈判到签约成单的全闭环流程：

```
[公域投放 / 官网线索]
          │
          ▼
   [客户公海池 (Pool)] ◄──── (超期无跟进自动回收) ────┐
          │ (销售认领 / 主管分配)                     │
          ▼                                          │
   [线索深入跟进 (Leads)]                             │
          │ (确认具备采购意向)                         │
          ▼                                          │
   [正式企业客户 (Customer)]                         │
          │ (创建销售商机)                             │
          ▼                                          │
   [阶段式商机漏斗 (Opportunity)]                      │
          │ - 方案报价                               │
          │ - 商务谈判                               │
          ▼                                          │
   [合同签约与回款 (Contract & Pay)]                  │
          │                                          │
          └─────────── (长期停滞归还公海) ─────────────┘
```

## 2. 客户公海池核心机制

为了解决销售团队“占坑不产出”以及客户资源私有化的痛点，平台内嵌高可用公海流转规则：
1. **防恶意占有配额 (Quota)**：每个销售根据星级设定私海客户上限（例如普通销售最多保留 50 个私海客户），达到上限后必须成交或释放，方可认领新客户。
2. **自动超时回收机制**：若私海客户超过 15 天未录入有效跟进记录，定时调度任务自动将该客户划归入公海池，供其他销售自由认领。
3. **公海保护期**：刚释放入公海的客户，原跟进销售在 7 天内不可重新捞取，保障资源在团队内充分流通。

## 3. 商机阶段漏斗推进与移动外勤

* **商机阶段看板**：支持拖拽式商机卡片，直观把控阶段转化率、预测下月成交金额与滞留周期；
* **移动外勤拜访**：销售现场拜访客户时，利用移动端 GPS 定位一键打卡签到，录入语音/文字跟进纪要，信息实时同步至 PC 控制台。
