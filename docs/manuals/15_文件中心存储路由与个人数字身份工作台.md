## 1. 可配置文件上传方式与业务目录路由 (`V74`)

在企业级多租户场景中，不同业务（如用户头像、AI 知识库文档、ERP 合同附件、财务发票）往往需要落盘到不同目录，且应支持在不改代码的情况下切换上传模式（服务端直传、预签名直传、分片上传、本地落盘）或切换底层存储引擎（Local / MinIO / OSS / COS / OBS / S3）。

### 1.1 核心模型与数据库设计 (`V74`)
1. **存储源配置增强 (`file_storage`)**：
   - `is_default`：标识当前租户的默认启用存储源（可通过 `POST /api/files/storages/{id}/set-default` 切换）；
   - `upload_mode`：默认上传方式（如 `DIRECT_SERVER`、`PRESIGNED`、`CHUNKED`、`LOCAL_DISK`）；
   - `default_folder`：默认基础目录（如 `uploads`）；
   - `path_pattern`：对象键模板（默认 `{folder}/{yyyy}/{MM}/{uuid}_{filename}`）；
   - `max_file_mb` / `allowed_exts`：单文件体积上限与扩展名白名单。
2. **业务目录路由表 (`file_upload_route`)**：
   - 按 `(tenant_id, biz_type)` 绑定路由规则，支持指定专属存储源 `storage_id`（为空时自动跟随租户当前默认启用存储源）、覆盖 `upload_mode`、配置目标文件夹 `target_dir` 与自定义 `path_pattern`；
   - 默认预置 `USER_AVATAR`（`avatars/users`）与 `AI_KNOWLEDGE`（`knowledge/docs`）两类路由规则。
3. **文件对象溯源字段 (`file_object`)**：
   - 记录实际命中的 `storage_id`、`upload_mode` 与解析后的 `target_dir`。

### 1.2 未配置存储源前置拦截 (Fail-Fast Guard)
为了避免在未配置任何可用存储源（或默认/全部存储源处于 `DISABLED` 状态）时用户上传失败才暴露异常：
* 后端在 `PlatformFileStorageGateway#checkAvailability(tenantId, bizType)` 与 `GET /api/files/storage-status?bizType=...` 中统一计算当前租户与目标业务的存储就绪状态（`configured`, `reasonCode`, `message`, `resolvedTargetDir`, `uploadMode` 等）；
* 若租户无 `ENABLED` 状态的存储源或对应路由绑定了未启用的存储源，前置探针返回 `configured = false` 及明确告警提示，前端上传视图（`FileUploadView.vue` / `FileStorageView.vue`）直接展示阻断引导横幅与「前往配置存储源」入口，上传接口也会快速拒绝并返回明确错误码；
* **当前实现边界说明**：`LOCAL` 存储适配器通过服务端磁盘路径实时落盘与流式下载（`/api/file/raw-upload` 与 `/api/file/raw-download/**`）闭环；对于 MinIO / OSS / COS / OBS / AWS S3 等远端对象存储，目前支持元数据配置、连通性探针 (`POST /api/files/storages/{id}/test`) 与路由编排，完整生产级 AWS SigV4 / 官方 SDK 直传签名仍在持续补全中。

### 1.3 管理端运维操作 (`web/src/views/file/`)
* **存储源维护 (`FileStorageView.vue`)**：新增/编辑存储源、设置 `upload_mode` 与 `default_folder`、一键设为租户默认源、执行连通性测试；
* **业务目录路由 (`FileUploadView.vue`)**：配置按业务类型（如 `COMMON`、`USER_AVATAR`、`CRM_CONTRACT`、`AI_KNOWLEDGE`）的独立上传方式与目标目录，并在页面实时预览当前生效的存储源状态与路径模板解析结果。

## 2. 企业级个人数字身份中心与云端工作台偏好 (`V74`)

天枢云基实现了 **PC 控制台 (`web/src/views/profile/ProfileView.vue`)** 与 **跨端移动工作台 (`mobile/src/pages/profile/profile.vue`)** 能力对齐的个人数字身份与安全工作台（后端接口 `/api/iam/profile/*`）。

### 2.1 六大核心模块能力
1. **个人数字名片与真实头像上传**：
   - 支持在线编辑昵称、姓名、手机号、邮箱、性别 (`gender`)、个人简介 (`bio`)、办公地点 (`work_location`)、分机/扩展联系方式 (`ext_contact`)、界面语言 (`locale`) 与时区 (`timezone`)；
   - 点击头像即可通过 `POST /api/iam/profile/avatar` 上传图片，后端自动路由至 `USER_AVATAR` 业务目录并回填 `iam_user.avatar_url`。
2. **组织归属与多任职上下文 (`organization`)**：
   - 联动标准化组织模块展示工号、所属组织主体/部门全路径、岗位以及主/辅任职生效周期；
   - 用户可在「身份与任职上下文切换」中按需切换当前工作任职（`PUT /api/auth/context`），立即刷新数据权限范围。
3. **云端工作台偏好同步 (`preferences_json`)**：
   - 通过 `PUT /api/iam/profile/preferences` 将 PC 控制台导航布局模式（左侧菜单 `side` / 顶部导航 `top`）、流光壁纸预设、紧凑密度、圆角等偏好持久化至云端；
   - 为避免刷新或刚登录后云端旧默认值覆盖用户在本地的显式选择，外壳组件（`ConsoleLayout.vue`）会在用户点击切换布局时同步写回云端与 `localStorage`，登录恢复时仅应用已显式保存过的偏好键值。
4. **安全评分、密码修改与 TOTP MFA**：
   - 实时计算展示账号安全评分（绑定手机、绑定邮箱、启用 TOTP MFA），提供带限流防刷保护的自助改密（`PUT /api/iam/profile/password`）与 TOTP 双因子开关引导。
5. **本人活跃会话自管理 (`online-sessions`)**：
   - 查看当前账号在 PC Web、移动 H5/小程序等终端的在线设备列表（`GET /api/iam/profile/sessions`）；
   - 支持单台设备下线（`DELETE /api/iam/profile/sessions/{sessionNo}`）或一键踢除其他全部设备（`DELETE /api/iam/profile/sessions/others`）。
6. **个人登录轨迹**：
   - 按时间倒序核对本人近期登录 IP、客户端信息与成功/失败状态，第一时间发现异地异常登录。
