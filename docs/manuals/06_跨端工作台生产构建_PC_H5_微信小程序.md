# 06. 跨端工作台生产构建 (PC / H5 / 微信小程序)

> **所属专栏**：天枢云基 PaaS 企业级数字化底座 · 第二卷 (生产部署与运维)  
> **文档版本**：v1.0.0 (Release)  
> **阅读对象**：前端开发工程师、移动端全栈工程师、发布运维人员  

---

## 1. PC 管理控制台生产编译

PC 管理端源码位于 `/web` 目录，基于 Vue 3 + TypeScript + Vite 5 + Element Plus 架构：

```bash
cd web

# 1. 安装项目依赖
npm install

# 2. 执行生产编译打包
npm run build
```
* **构建产物**：`web/dist`
* **部署方式**：将 `dist` 目录内的静态资源复制到 Nginx Web 根目录（如 Docker 镜像的 `/usr/share/nginx/html`），配合 Nginx 配置的 `try_files $uri $uri/ /index.html;` 实现 HTML5 History 路由模式。

## 2. uni-app 跨端移动工作台构建发布

移动端源码位于 `/mobile` 目录，采用 uni-app 跨端技术，**一套代码即可发行构建为 H5 移动工作台与微信小程序**。

### 2.1 H5 移动工作台构建
```bash
cd mobile
npm install
npm run build:h5
```
* **构建产物**：`mobile/dist/build/h5`
* **部署方式**：将生成的所有静态文件拷贝至 Nginx Web 服务器的 `/usr/share/nginx/mobile` 目录下，并在 Nginx 中开启 `/mobile/` 路由段重定向。

### 2.2 微信小程序编译与审核发布全流程
```bash
cd mobile
npm run build:mp-weixin
```
* **构建产物**：`mobile/dist/build/mp-weixin`
* **上线步骤**：
  1. 下载并打开官方 **微信开发者工具**；
  2. 点击「导入项目」，选择目录 `mobile/dist/build/mp-weixin`；
  3. 输入企业注册的小程序 `AppID`，确认进入项目；
  4. 登录 **微信公众平台 (mp.weixin.qq.com)**，在「开发」->「开发管理」->「服务器域名」中，将生产 API 域名加入白名单：
     - `request合法域名`：`https://api.tianshu.cloud`
     - `uploadFile合法域名`：`https://api.tianshu.cloud`
     - `downloadFile合法域名`：`https://api.tianshu.cloud`
  5. 在微信开发者工具右上角点击「上传」，填写发布版本号（如 `1.0.0`）；
  6. 在微信公众平台后台提交版本审核，审核通过后点击全量发布。
