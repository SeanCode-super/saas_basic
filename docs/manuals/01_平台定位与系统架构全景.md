## 1. 平台定位与设计理念

**天枢云基 (Tianshu Cloud)** 是一套面向大中型企业集团、SaaS 运营商及数字化解决方案商的**云原生企业级多租户应用底座**。

天枢云基致力于解决企业多租户软件开发中的共性基础设施难题，提供开箱即用的：
* **多租户数据与组织隔离**：原生支持字段级共享隔离、Schema 隔离及独立库隔离；
* **企业级统一身份与权限体系 (IAM)**：支持集团-企业-部门-岗位-员工五级架构，RBAC 三位一体权限（菜单树、按钮指令、行级数据范围 DataScope）；
* **工业级 Flowable BPMN 2.0 工作流引擎**：支持加签、会签、多级驳回、转办与流转轨迹透视；
* **开箱即用业务中台**：内嵌 CRM 客户全生命周期与商机漏斗、ERP 进销存与云仓物料、聚合收银台及单据套打中心；
* **AI 智能中枢与异步导出中心**：集成多云模型网关、⌘K 自然语言 & NL2SQL 副驾驶、企业知识库 Hybrid RAG、Agent 工坊、LoRA 微调评测，以及带水印/脱敏/定时投递的全局异步导出队列；
* **可配置存储路由与企业级个人工作台**：支持 Local / MinIO / OSS / COS / OBS 多存储源与按业务目录路由（含无启用存储源前置拦截），支持 PC + 移动端同步头像上传、云端工作台偏好同步与多端会话自管理；
* **现代化极致视觉体验**：PC 端搭载 iOS 27 / visionOS 流光毛玻璃设计语言（支持侧边/顶部双导航模式及云端偏好同步），移动端搭载悬浮灵动岛毛玻璃 TabBar；
* **开放集成与企业互联**：内置 Open API 签名鉴权网关与 SAML/OIDC/企微/钉钉 SSO 联合认证。

## 4. 多租户数据隔离机制原理

天枢云基默认采用企业最主流的**字段级共享数据库隔离机制（Schema-Sharing with Tenant Column）**：

1. **统一数据表隔离字段**：所有多租户业务表（用户、部门、客户单据、ERP 物料流水等）均包含 `tenant_id` 或 `tenant_code` 列。
2. **底层 AST SQL 拦截注入**：
   - 基于 MyBatis-Plus 的 `TenantLineInnerInterceptor`，拦截器在 SQL 语法树分析阶段（JSQLParser）自动在 `SELECT / INSERT / UPDATE / DELETE` 语句末尾拼装 `WHERE tenant_id = ?` 条件；
   - 业务开发工程师在编写业务 SQL 时无需手工关心租户隔离，从根源杜绝数据跨租户越权。
3. **超管特权与租户空间**：
   - 平台超管租户（ID 为 `1` 或编码 `platform`）拥有系统全量空间巡检与管控能力；
   - 租户普通管理员或员工（如 `tenant-ce`）登录后强制绑定专属租户上下文，无法跨越租户边界。
