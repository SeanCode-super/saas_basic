## 1. 服务编排与发布中台定位与架构

在传统企业级多租户与微服务体系中，开发与运维人员通常面临多模块构建繁琐、环境依赖复杂、端口冲突排查耗时以及日志分散等痛点。**天枢云基服务编排与发布中台 (Tianshu DevOps Orchestration & CI/CD Center)** 提供全自主可控的研发运维一体化底座，原生支持：

* **双驱动编排引擎 (Dual-Engine Orchestration)**：
  * **主机进程树引擎 (ProcessTree)**：通过递归跨平台进程树算法（PID 追踪与子进程深度遍历），实现本地及宿主机后台进程的毫秒级纳管、健康探活与安全销毁；
  * **容器编排引擎 (Docker Engine)**：无缝桥接 Docker API / Docker Compose，支持容器化微服务的启停调度与健康检测。
* **本地 CI 构建流水线 (Local CI Pipeline)**：无需外置第三方 Jenkins 即可直接在平台内触发多技术栈（Maven / npm / Go / Python / Docker）的一键构建编译与流式输出。
* **全生命周期版本化制品归档 (Artifact Versioning & Rollback)**：自动计算打包产物 MD5 指纹、校验归档版本，支持一键热退滚至历史任一稳定版本。
* **Server-Sent Events (SSE) 实时流式终端**：基于 HTTP/2 与 SSE 协议的高性能日志下发，内置智能滚动锁定、瞬时反压阻断与关键字高亮检索。

## 3. 运维实战操作指南

### 3.1 服务的启停与防抖状态机

天枢云基服务编排中台彻底消除了传统运维界面因异步延时导致的“过早提示已停止/已启动”的体验断层：
1. **停止服务**：
   * 点击操作列【停止】按钮，状态立即流转为 `STOPPING`（停止中），操作按钮自动禁用防重击；
   * 界面卡片顶部展示通透流光发丝级进度条与微秒级元信息摘要（`zero layout shift`，不破坏页面整体网格排版）；
   * 后端通过 `ProcessHandle` 优先尝试友好下线（SIGTERM），超时自动触发跨平台进程树强制销毁（SIGKILL）；
   * 只有在底层端口真正释放且进程完全注销后，平台才弹出明确的“服务已安全停止”成功反馈。
2. **启动服务**：
   * 点击【启动】按钮，系统立即触发 `STARTING` 状态机；
   * 后端启动探测器持续轮询目标服务监听端口（如 `8080` 或 `8085`），直到端口握手成功后正式切入 `RUNNING` 状态。

### 3.2 本地 CI 一键编译与构建

开发或测试人员在控制台无需打开终端，即可一键触发服务重构：
1. 点击服务卡片上的【编译】按钮，弹出编译构建控制台；
2. 支持使用服务配置的默认命令（如 `mvn clean package -pl saas-basics-workflow-app -am -DskipTests` 或 `npm run build`），亦可临时覆盖构建指令；
3. 点击【触发构建】后，系统生成全球唯一构建流水线编号（如 `B20261103-185308`）；
4. 构建控制台实时拉取标准输出流（Stdout）与错误流（Stderr），构建完成后自动展示编译耗时（如 `9.31s`）；
5. 编译产物自动计算 `MD5` 校验码并归档至平台制品库（例如 `workflow-app-v20261103-185318-saas-basics-workflow-app-0.1.0-SNAPSHOT.jar`）。

### 3.3 制品版本管理与秒级回退

1. 点击服务卡片上的【制品】按钮，打开历史发布档案面板；
2. 系统展示历次成功归档的制品清单，包含版本代号、文件名、文件大小、MD5 指纹及上传/生成时间；
3. **安全回滚**：当新发布的版本出现严重线上缺陷时，只需在目标历史版本点击【回滚至此版本】，系统将自动备份当前生产文件，将归档制品安全覆写至发布目录，并自动执行平滑重启。

### 3.4 实时流式日志终端 (SSE Live Stream)

1. 点击服务卡片上的【日志】按钮，进入仿 macOS / iTerm2 拟态的流光深色终端视窗；
2. **自动滚动与智能吸底**：
   * 默认开启【自动滚屏：开启】，随日志持续推送自动保持在视窗底部；
   * 用户向上翻阅历史日志时，系统智能识别滚动偏离，自动切换为【自动滚屏：已暂停】，并在视窗右下角弹出动效悬浮按钮【↓ 恢复滚动】，点击即可一键瞬移回最新日志行；
3. **实时检索与导出**：
   * 支持通过顶部搜索栏进行关键字实时高亮过滤；
   * 支持一键【清屏】与【下载日志】导出为本地 `.log` 文本文件。

## 4. 生产安全防护与架构规范

1. **防命令注入防火墙**：
   * 所有由界面提交的自定义启停脚本与编译命令，均经过后端严格的正则白名单与非法字符过滤（拦截注入管道符 `;`、`&&` 恶意提权脚本等危险操作）。
2. **端口冲突探针**：
   * 在新建纳管服务或启动前，系统主动扫描目标端口占用情况，一旦发现端口被第三方程序抢占，立即给出明确占用进程预警，严禁盲目覆盖。
3. **全链路审计追踪**：
   * 所有针对服务的启动、停止、重启、构建、制品上传与版本回滚操作，统一通过 `AuditRecorder` 自动记录至平台安全审计日志中心，责任到人，全迹留存。
