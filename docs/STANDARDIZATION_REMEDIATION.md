# 标准化迁移台账

状态：`Active`

本台账记录当前代码与标准化目标之间的已知差异。关闭条目必须同时删除旧路径、增加回归测试并更新迁移文档，不能只增加一条新路径后保留旧行为。

| ID | 当前偏差 | 目标状态 | 里程碑 | 发布阻断 |
|---|---|---|---|---|
| STD-001 | V1-V24 包含固定语言、时区、演示联系方式和 `.local` 地址 | 安装时显式配置或协议协商；演示数据移出生产迁移 | M1/M5 | 是 |
| STD-002 | 用户与租户初始化仍可创建固定默认密码 | 邀请、一次性凭证或外部身份供应，不存在内置明文密码 | M2 | 是 |
| STD-003 | 新密码仍使用无盐 SHA-256 | DelegatingPasswordEncoder，BCrypt/Argon2id，成功登录升级旧哈希 | M2 | 是 |
| STD-004 | 自定义认证过滤器和权限拦截器 | Spring Security filter chain、方法授权、OIDC/OAuth 2.1 入口 | M2 | 是 |

## 执行规则

- 每个实现 PR 在描述中关联一个或多个 `STD-*` 条目。
- 新增标准化偏差必须先更新本台账并获得架构评审，不能作为隐含技术债提交。
- 标记完成前必须运行空库、升级、负向安全、公开契约和兼容性测试。
- v0.1 发布时所有“发布阻断”为“是”的条目必须关闭。
